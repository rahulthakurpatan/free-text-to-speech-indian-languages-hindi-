What are Gemini TTS voices?

Gemini text-to-speech provides named voice options that you select when generating audio. Google's Gemini API documentation lists 30 prebuilt voices, including Puck, Kore, Charon and Aoede. Each comes with a short style descriptor such as “Upbeat” or “Informative.” Those descriptors are useful starting points, not a guarantee that a voice will suit every language or script.

Different Google speech products and model generations have different voice-selection features. The newer Gemini 3.8 Interactions API also documents an extended voice library and custom voice workflows; do not assume those features are available in older Generate Content or Cloud Text-to-Speech endpoints.

Which voices should you audition first?

Use the official descriptors to make a shortlist, then run your own listening test:

  • Explainer or tutorial: audition Charon (Informative), Iapetus (Clear), Erinome (Clear) and Sadaltager (Knowledgeable).
  • Friendly creator intro: audition Puck (Upbeat), Achird (Friendly) and Zubenelgenubi (Casual).
  • Gentle storytelling: audition Achernar (Soft), Vindemiatrix (Gentle), Sulafat (Warm) and Callirrhoe (Easy-going).
  • Energetic short video: audition Zephyr (Bright), Sadachbia (Lively) and Fenrir (Excitable).
  • Measured documentary: audition Schedar (Even), Gacrux (Mature) and Rasalgethi (Informative).

These are editorial suggestions inferred from style labels—not empirical “best voice” rankings. Some voices will perform differently across accents, languages and longer scripts.

A repeatable 60-second voice comparison

  1. Write a 50–80-word test script containing a question, one number, a proper noun and a short emotional sentence.
  2. Generate the same script with three candidate voices, keeping the model and other settings constant.
  3. Listen with headphones and a phone speaker. Score intelligibility, tone fit, natural pauses, volume and pronunciation.
  4. Repeat the test in the target language. A good English voice is not automatically the best Hindi voice.
  5. For a long-form project, test a full paragraph before committing to an entire audiobook.

Example Hindi test: नमस्कार! आज हम जबलपुर की एक छोटी कहानी सुनेंगे। क्या आप तैयार हैं? यह कहानी तीन दोस्तों की है। Check the place name, numeral and question intonation.

Choosing voices for Hindi and other languages

Google's Gemini speech-generation documentation lists supported languages, and Cloud TTS documentation separately lists language availability by model. Always consult the documentation for the exact endpoint you use. Do not treat a model's general multilingual support as proof that every named voice handles every language equally well.

For Hindi, Marathi, Tamil, Telugu, Kannada, Malayalam, Bengali or Arabic scripts, compare a native-script paragraph rather than judging solely from an English demo. Test names, numbers, abbreviations and code-switching. Avoid assuming a voice's short style label specifies a particular regional accent.

How voice selection differs between Gemini APIs

In the Gemini API's documented Generate Content TTS examples, a prebuilt voice can be selected using the voice_name field within the speech configuration. The newer Interactions API and Google Cloud TTS use their own request shapes and feature sets. Do not paste a field from one API into another without checking the corresponding documentation.

Voice selection checklist:
1. Confirm the exact model and API endpoint.
2. Check the supported voice list for that endpoint.
3. Set the voice using the documented field.
4. Generate a short test and listen.
5. Save the voice and model names for repeatability.

This is a workflow checklist, not executable API JSON. For full examples, use Google's current speech-generation guide.

Frequently asked questions

How many prebuilt Gemini TTS voices are listed?

Google's Gemini API speech-generation documentation lists 30 prebuilt voice options. Newer endpoints may offer additional library or custom voices.

Is Puck better than Kore?

Neither is universally better. Google describes Puck as Upbeat and Kore as Firm. Compare both using your actual content.

Can one Gemini voice read Hindi and English?

Multilingual capability depends on the model and endpoint. Test mixed-language text and pronunciation before production.

Can I hear samples before generating a long recording?

Google's documentation directs users to Google AI Studio to listen to voice options. A short sample is the best practical starting point.
