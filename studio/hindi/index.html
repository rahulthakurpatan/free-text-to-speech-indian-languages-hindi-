How to get a Gemini API key
  1. Open the Google AI Studio API Keys page using the button below.
  2. Sign in with your Google account and select or create a project.
  3. Select Create API key, follow Google's prompts, then copy the new key.
  4. Return here and paste it into the Gemini API key field. Keep Remember on this device checked if you want this browser to reuse it.

GOOD TO KNOW

Hindi Studio FAQs

How do I create Hindi text to speech?

Paste a Hindi or Hinglish script, add your Gemini API key, choose a voice and direction, then select Generate Hindi voice.

Do I need my own Gemini API key?

Yes. Vani Studio uses a bring-your-own-key model. Google controls the quota, terms and any applicable charges on your API account.

How do I get a Gemini API key?

Open Google AI Studio, sign in, select or create a project, choose Create API key and copy it into this studio. Use a dedicated key restricted to the Gemini API.

Is my API key stored by Vani?

When Remember on this device is checked, the key is stored in this browser's local storage until you remove it. It is not sent to Vani's server; it is sent to Google's Gemini API for generation. Page scripts for analytics, ads and notifications also run in this browser context.

Can I download the generated Hindi voice?

After generation succeeds, preview the audio on this page and download it as a WAV file.

Will Hindi pronunciation always be perfect?

Pronunciation depends on the selected voice, script formatting and model behavior. Listen for names, numbers and tricky words before publishing.
